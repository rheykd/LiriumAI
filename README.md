# LiriumAI

Текущая версия — **1.1**; [описание новых функций](docs/FEATURES_1.1.md). [Скачать APK](https://github.com/rheykd/LiriumAI/releases/latest).

Android-приложение для локальных GGUF-моделей, пользовательского API и доступа к моделям телефона по Wi-Fi.

## Возможности

- Независимые чаты с боковой панелью, сохранением на устройстве и удалением.
- Локальный чат со стримингом, изображения через llama.cpp / libmtmd.
- Каталог локальных моделей: докачка, скорость и примерное оставшееся время.
- Настройки: шрифт, интернет, доступ к общим файлам, ползунок размера 1–10 ГБ, свой каталог JSON/URL.
- Системная инструкция с правилами использования инструментов без подмены имени модели.
- Удаление скачанных моделей: каталог → скачанные → удалить с устройства.
- Montserrat Bold по умолчанию; также Montserrat Regular, Light и AA Strejen.
- Пользовательский OpenAI-совместимый API: адрес, ключ, имя модели, передача фото.
- Поиск в интернете и чтение страниц при включённом доступе модели к интернету.
- Wi-Fi-веб-панель: локальные модели исполняются на телефоне, другие устройства используют браузер.
- Быстрый и детальный режимы фото, тест зрения с числом и цветными квадратами.
- Иконка из «Неоновые синие стеклянные капсулы.png».

## Использование

1. Скачайте и выберите модель в каталоге.
2. Откройте настройки кнопкой с шестерёнкой.
3. Для внешней модели заполните API, ключ и имя модели, включите «использовать свой API».
   В каталоге остаются только скачиваемые локальные модели.
4. Для Wi-Fi-панели включите «хостинг по wifi». Откройте показанный адрес вида
   http://192.168.1.5:8080 на другом устройстве в той же сети.
   Пароль по умолчанию 123; меняется в настройках телефона.
5. Для InternVL3 выберите быстрый режим фото при долгой обработке.
   Детальный сохраняет больше деталей и требует больше времени на CPU.

Wi-Fi-панель пока принимает текст. Один общий движок, запросы последовательные.
Сессии приложения и LAN разделены; переход между ними сбрасывает нативный контекст.
У каждого вошедшего браузера своя история и выбранная модель; список сессий и отключение доступны на телефоне. Хостинг включается вручную после перезапуска приложения.
Переключатель интернета управляет поиском и страницами для модели; скачивание и внешнее API независимы от него.
Явные просьбы посмотреть в интернете запускают поиск до ответа модели.
Сведения часов устройства передаются только когда нужны для вопроса; приветствия и обычная беседа не получают дату и часовой пояс.
Поиск: один запрос DuckDuckGo Lite, проверка соответствия теме и максимум одна страница.
Модели передаются короткие выдержки и источник; повторного обхода ссылок после результата нет.
Если подходящих источников нет, посторонние данные не подставляются. Отдельный ключ не требуется. Сайты могут ограничивать доступ;
небольшие модели могут не соблюдать команды поиска.

## Сборка и проверки

Android 10+, arm64-v8a, compileSdk / targetSdk 37. JDK 21, AGP 8.13.2,
Gradle 8.14.3, NDK 29.0.13113456, CMake 3.31.6.

Склонируйте проект с закреплённой версией llama.cpp:

```sh
git clone --recurse-submodules https://github.com/rheykd/LiriumAI.git
cd LiriumAI
```

Установите JDK 21 и Android SDK (Platform 37, Build Tools 37.0.0,
NDK и CMake указанных выше версий). Укажите SDK в `local.properties`
(`sdk.dir=...`) или переменной `ANDROID_HOME`, JDK — в `JAVA_HOME`.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
node scripts/test-web-panel.cjs
```

Тестовый APK: `app/build/outputs/apk/debug/app-debug.apk`. Для Linux/macOS используйте `./gradlew`.

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Архитектура и ограничения: [PROJECT.md](PROJECT.md).

### Подписанная release-сборка

Скопируйте `release-signing.properties.example` в `release-signing.properties`
и укажите собственный keystore и пароли. Файл исключён из Git.
Можно хранить настройки вне проекта и задать путь переменной
`LIRIUM_SIGNING_PROPERTIES`. Без настроек подписи release APK будет неподписанным.

```powershell
.\gradlew.bat :app:assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`.
Храните резервную копию ключа и паролей: для обновлений нужна та же подпись.
Официальная 1.0 подписана постоянным ключом релизов. Для перехода с ранних
тестовых APK с отладочной подписью потребуется удалить тестовое приложение;
при удалении Android удалит также его чаты и скачанные модели.
Публичная 1.0 имеет `versionCode = 10`; следующая сборка 1.1 — `versionCode = 11` и обновляется с той же подписью.

## Файлы устройства

Настройки → «доступ моделей к файлам», затем разрешите общий доступ в системном
окне Android. Root не требуется. Доступны общие тома, исключены защищённые каталоги
и приватные данные приложений. Локальные модели и выбранный вами API могут читать
текст и список файлов; для фото/PDF используйте вложения. Через API прочитанный текст
отправляется вашему провайдеру. Wi-Fi-панель доступа к файлам не получает.

Перед каждой записью или удалением приложение показывает путь и изменение, которое
можно подтвердить или отменить. Переключатель в настройках отключает файловые инструменты.
Пример запроса: «Покажи список файлов в primary/Download».

## Модели и Android

15 локальных моделей — от Qwen2.5 0.5B до Qwen3 14B, включая Gemma 3 12B со зрением.
Таблица источников, размеров и ориентиров ОЗУ: [каталог](docs/MODEL_CATALOG.md).
В настройках максимальный размер выбирается ползунком до 10 ГБ. Файлы большой модели
могут помещаться на накопителе, но не помещаться в оперативную память.

Поддерживается установка на Android 10 и новее с 64-битной ARM-системой (arm64-v8a).
CPU-бэкенд использует базовую ARMv8-A и не требует dotprod. compileSdk/targetSdk 37 —
это целевая версия API, а не минимальная версия Android. Реальные запуски на всех
версиях Android и всех моделях телефонов не проверялись.

## Несколько чатов

Кнопка с тремя линиями слева вверху открывает список. «Новый чат» или плюс создают
отдельную сессию с пустым контекстом. Переключение возвращает историю выбранного чата,
не подмешивая другие разговоры. Сообщения, черновики и копии вложений сохраняются
после закрытия приложения. «Удалить» в панели удаляет выбранный чат с подтверждением;
исходные файлы на устройстве не удаляются. Перед переключением остановите текущий ответ.

На диске сохраняется полная переписка, в модель передаётся ограниченный её контекст.
При возврате к локальному чату текстовый контекст восстанавливается; старые фото для
повторного анализа деталей нужно прикрепить заново. Проверки самой модели на телефоне
для этой версии ещё не проводились.
